Firebase Setup Required — prices won't sync across devices until this is done

  1. Go to console.firebase.google.com and click Add project
  2. Enter any project name (e.g. arora-sweets), click through and create the project
  3. In the left sidebar click Build → Realtime Database → Create Database
  4. Choose any location and select Start in test mode → Enable
  5. Copy the Database URL shown at the top (looks like https://arora-sweets-default-rtdb.firebaseio.com)
  6. Go to Project Settings (gear icon) → Service Accounts → Database Secrets → click Show → copy the secret
  7. Open the file js/firebase-config.js and paste the URL into dbUrl and the secret into secret
  8. Save the file, deploy/upload your site, then refresh this page
Firebase is not configured — changes will only be saved in this browser. Follow the setup steps above to enable cross-device sync.
